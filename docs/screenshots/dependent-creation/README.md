The `baseline-*` captures use application source from
`682320ca99e3254fd7d0d3bd917099138c206990`. The subsequent main update
`1de893e64c88e652dfafdd56927b0f20eebf9feb` changes documentation only.
The `final-*` captures exercise the typed creation input.

Both use the synthetic household administrator, English, light appearance and
the same completed minor-creation form at 1440×1000 and 390×844.

and checks the saved email, dependent type, capacity and active carer link
backed by a guardian declaration. No template or styling changes are intended.
